# Localized Resource Support

The `ResourceIndex` now supports locale-aware filtering and translated titles/descriptions.

- Store resources in a default locale such as `en`.
- Provide `translations` for supported locales.
- Search with `locale="es"` or another supported locale to find content in that language.

Supported locales: `en`, `es`, `fr`, `pt`.

This feature is designed to help contributors maintain a searchable knowledge base for multilingual community infrastructure planning.
