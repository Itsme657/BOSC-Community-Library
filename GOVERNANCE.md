# Governance

## Maintainer Role

Maintainers are responsible for reviewing contributions, enforcing community standards, protecting project scope, and keeping decisions transparent.

## Decision Making

Routine changes can be accepted through pull request review. Larger changes, including architecture direction, security-sensitive examples, or governance updates, should include an issue or design note before implementation.

## Review Principles

- Prefer clear evidence over authority.
- Keep discussions public unless privacy or security requires confidentiality.
- Record important decisions in documentation.
- Make it easy for new contributors to understand why a decision was made.

## Release Readiness

A change is ready to merge when it is documented, tested where appropriate, legally compatible with the project license, and aligned with the Code of Conduct.
